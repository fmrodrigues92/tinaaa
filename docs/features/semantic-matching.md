# Busca Semântica por Aderência

## Descrição

Encontrar experiências, projetos e conquistas relacionados aos requisitos da vaga ou à pergunta informada.

## Objetivo

Recuperar evidências profissionais relevantes para responder perguntas ou avaliar aderência a uma vaga.

## Escopo inicial

- Buscar evidências por similaridade semântica.
- Combinar busca semântica com filtros estruturados quando necessário.
- Retornar evidências com pontuação e origem.
