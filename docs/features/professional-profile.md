# Cadastro do Perfil Profissional Detalhado

## Descrição

Registrar experiências, empresas, cargos, períodos, responsabilidades, resultados, tecnologias e contexto real.

## Objetivo

Criar a base principal de informações profissionais reais que será usada posteriormente pela busca semântica e pela geração de respostas.

## Escopo inicial

- Cadastrar experiências profissionais.
- Registrar empresa, cargo, período e descrição contextual.
- Registrar responsabilidades, resultados e tecnologias utilizadas.
