# Dashboard Pessoal

## Descrição

Apresentar visão geral de experiências cadastradas, vagas analisadas, perguntas respondidas, lacunas recorrentes e evolução da base profissional.

## Objetivo

Dar uma visão rápida do progresso da base profissional e do uso do sistema.

## Escopo inicial

- Exibir contadores principais.
- Mostrar vagas recentes.
- Mostrar pendências de revisão e lacunas recorrentes.

## Status
