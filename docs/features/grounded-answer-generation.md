# Geração de Respostas Fundamentadas em Experiências Reais

## Descrição

Criar respostas específicas usando evidências cadastradas, evitando frases genéricas, exageros ou informações inventadas.

## Objetivo

Gerar respostas úteis para vagas e entrevistas sem perder fidelidade à trajetória real do desenvolvedor.

## Escopo inicial

- Gerar resposta a partir de uma pergunta e evidências recuperadas.
- Indicar quando a evidência for insuficiente.
- Evitar afirmações sem suporte.

## Status

Revisado; implementação inicial criada com providers `extractive`, `openai` e `ollama`.
