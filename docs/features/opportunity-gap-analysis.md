# Análise de Gaps da Vaga

## Descrição

Identificar requisitos com boa aderência, pontos fracos, lacunas reais e sugestões de como responder com honestidade.

## Objetivo

Ajudar o desenvolvedor a entender aderência à vaga sem forçar correspondências falsas.

## Escopo inicial

- Comparar requisitos da vaga com evidências cadastradas.
- Classificar aderência por requisito.
- Sugerir respostas honestas para pontos fracos.
