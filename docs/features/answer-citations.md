# Citações e Rastreabilidade das Experiências Usadas

## Descrição

Mostrar quais experiências sustentaram cada resposta gerada, permitindo revisar a origem de cada argumento.

## Objetivo

Garantir confiança, revisão humana e auditabilidade das respostas geradas.

## Escopo inicial

- Relacionar resposta gerada com evidências usadas.
- Exibir origem das evidências.
- Permitir revisar o suporte antes de usar a resposta.
